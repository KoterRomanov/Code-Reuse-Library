# Data Structures

This directory contains implementations of fundamental data structures.

## Contents

### Linear Data Structures
- **Array**: Fixed-size sequential collection
- **Linked List**: Dynamic sequential collection with nodes
- **Stack**: LIFO (Last In First Out) data structure
- **Queue**: FIFO (First In First Out) data structure
- **Deque**: Double-ended queue

### Non-Linear Data Structures
- **Binary Tree**: Hierarchical tree structure
- **Binary Search Tree**: Ordered binary tree
- **AVL Tree**: Self-balancing binary search tree
- **Red-Black Tree**: Self-balancing binary search tree
- **B-Tree**: Self-balancing tree for databases
- **Heap**: Complete binary tree for priority queue
- **Trie**: Tree for string searching
- **Graph**: Network of nodes and edges

### Hash-Based Structures
- **Hash Table**: Key-value pair storage
- **Hash Set**: Unique element collection

## Usage

Each data structure includes:
- Complete implementation
- Common operations (insert, delete, search, traverse)
- Time and space complexity analysis
- Usage examples
- Test cases
