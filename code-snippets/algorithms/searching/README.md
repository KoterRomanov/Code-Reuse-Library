# Searching Algorithms

This directory contains implementations of various searching algorithms.

## Contents

- **Linear Search**: Sequential search through elements
- **Binary Search**: Efficient search in sorted arrays
- **Jump Search**: Block-based search algorithm
- **Interpolation Search**: Improved binary search for uniformly distributed data
- **Exponential Search**: Search algorithm for unbounded/infinite arrays
- **Ternary Search**: Divide-and-conquer search algorithm
- **Fibonacci Search**: Search using Fibonacci numbers

## Usage

Each searching algorithm includes:
- Implementation in multiple languages
- Time and space complexity analysis
- Usage examples and best use cases
- Test cases

## Performance Comparison

| Algorithm | Best Case | Average Case | Worst Case | Space | Requirements |
|-----------|-----------|--------------|------------|-------|--------------|
| Linear Search | O(1) | O(n) | O(n) | O(1) | None |
| Binary Search | O(1) | O(log n) | O(log n) | O(1) | Sorted array |
| Jump Search | O(1) | O(√n) | O(√n) | O(1) | Sorted array |
