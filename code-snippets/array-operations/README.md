# Array Operations

This directory contains common array manipulation utilities and algorithms.

## Contents

- **Array Reversal**: Reverse array elements
- **Array Rotation**: Rotate array left/right
- **Array Flattening**: Flatten nested arrays
- **Array Filtering**: Filter elements by condition
- **Array Mapping**: Transform array elements
- **Array Reduction**: Reduce array to single value
- **Array Chunking**: Split array into chunks
- **Array Deduplication**: Remove duplicate elements
- **Array Intersection**: Find common elements
- **Array Union**: Combine unique elements
- **Array Difference**: Find different elements
- **Array Shuffling**: Randomize array order
- **Array Partitioning**: Partition by condition
- **Subarray Operations**: Find max/min subarray sum

## Usage

Each operation includes:
- Efficient implementation
- Time and space complexity
- In-place vs. new array options
- Usage examples
- Edge case handling
