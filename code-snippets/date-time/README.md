# Date and Time Handling

This directory contains utilities for date and time operations.

## Contents

- **Date Formatting**: Format dates in various formats
- **Date Parsing**: Parse string to date object
- **Date Arithmetic**: Add/subtract days, months, years
- **Date Comparison**: Compare dates
- **Time Zone Conversion**: Convert between time zones
- **Time Difference**: Calculate time between dates
- **Business Days**: Calculate working days
- **Date Validation**: Validate date strings
- **Relative Time**: Format as "2 hours ago", "in 3 days"
- **Calendar Operations**: Get month/year info
- **ISO 8601 Handling**: Parse and format ISO dates
- **Timestamp Conversion**: Unix timestamp utilities

## Usage

Each utility includes:
- Cross-platform implementation
- Timezone-aware operations
- Locale support
- Usage examples
- Common date format patterns
