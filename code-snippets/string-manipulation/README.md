# String Manipulation

This directory contains reusable string manipulation utilities and algorithms.

## Contents

- **String Reversal**: Reverse string characters
- **Palindrome Check**: Check if string is palindrome
- **Substring Search**: Find substring in string (KMP, Boyer-Moore)
- **String Matching**: Pattern matching algorithms
- **Case Conversion**: Upper/lower/title case conversion
- **Trim Functions**: Remove whitespace
- **String Splitting**: Split by delimiter
- **String Joining**: Concatenate with separator
- **Character Frequency**: Count character occurrences
- **Anagram Detection**: Check if two strings are anagrams
- **String Encoding**: URL encoding, Base64, etc.
- **String Validation**: Email, phone, URL validation

## Usage

Each utility includes:
- Implementation with clear documentation
- Multiple approach options (regex, iterative, recursive)
- Performance considerations
- Edge case handling
- Usage examples
