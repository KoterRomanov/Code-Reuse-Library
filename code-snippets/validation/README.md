# Data Validation

This directory contains data validation utilities and functions.

## Contents

- **Email Validation**: Validate email addresses
- **Phone Validation**: Validate phone numbers (various formats)
- **URL Validation**: Validate web URLs
- **IP Address Validation**: Validate IPv4/IPv6 addresses
- **Credit Card Validation**: Validate card numbers (Luhn algorithm)
- **Password Strength**: Check password complexity
- **Username Validation**: Validate username format
- **Postal Code Validation**: Validate zip/postal codes
- **Date Validation**: Validate date strings
- **Number Validation**: Validate numeric input
- **File Extension Validation**: Check file types
- **Form Validation**: Complete form validation utilities

## Usage

Each validator includes:
- Regex-based validation
- Custom validation logic
- Error message generation
- Multi-language support
- Usage examples
- Test cases
